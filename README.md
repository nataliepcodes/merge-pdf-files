# merge-pdf-files
This program merges multiple pdf files into one file by using Python programming language, and pypdf library.

## Installation
Install pypdf
```
pip install pypdf
```
pypdf for Anaconda: 
```
$ conda install conda-forge::pypdf
```
## Run
```
python -u merge-files.py
```
